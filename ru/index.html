SilentBeep

Держите динамики и наушники в активном состоянии с помощью неслышимых аудиоимпульсов.

Скачать для Windows GitHub

Зачем SilentBeep?

Многие аудиоустройства переходят в режим ожидания после короткой паузы. Когда вам наконец понадобится звук, устройство просыпается с заметной задержкой. SilentBeep предотвращает это, издавая сверхнизкочастотные импульсы, которые человек не слышит.

Возможности

По-настоящему бесшумно

Использует частоты ниже порога слышимости (по умолчанию 10 Гц).

Работа в трее

Работает в фоне с маленькой иконкой в системном трее и удобным управлением.

Настройка

Настройте интервал, частоту, длительность, аудиоустройство и ночной режим.

Автозапуск

Может запускаться вместе с Windows и автообновляться из GitHub Releases.

Приватность

Не собирает телеметрию, аналитику или данные об использовании.

Бесплатная

Распространяется под свободной лицензией MIT.

Как установить

  1. Скачайте SilentBeep-win-Setup.exe со страницы Releases.
  2. Запустите установщик. Он устанавливает приложение для текущего пользователя в %LocalAppData%\SilentBeep\ без UAC.
  3. SilentBeep запустится автоматически и будет держать аудиоустройство готовым к работе.
