SilentBeep — это утилита для Windows, которая не даёт динамикам засыпать, периодически воспроизводя неслышимые аудиоимпульсы.

## Зачем?

Многие аудиоустройства и динамики переходят в спящий режим после периода бездействия, из-за чего появляется задержка, когда нужно воспроизвести звук. SilentBeep держит устройство в активном состоянии за счёт очень короткого низкочастотного импульса, который не слышен человеку.

## Возможности

- **Бесшумная работа** — частоты ниже порога слышимости (по умолчанию 10 Гц).
- **Работа в трее** — работает в фоне с иконкой в системном трее.
- **Современное окно настроек** — в стиле Fluent UI с живым статусом.
- **Автозапуск** — опциональный запуск вместе с Windows.
- **Настройка** — интервал, частота, длительность под ваши нужды.
- **Выбор устройства** — выбор аудиовыхода.
- **Стартовый джингл** — приятный трёхнотный сигнал при запуске (на выбранном устройстве).
- **Ночной режим** — опциональная пауза сигналов в заданные ночные часы.
- **Локализация** — английский и русский интерфейс, переключение темы (Система / Светлая / Тёмная).

## Загрузка

Скачайте последнюю версию со страницы [Releases](https://github.com/dosoft/SilentBeep/releases).

## Установка

1. Загрузите `SilentBeep-win-Setup.exe` со страницы [Releases](https://github.com/dosoft/SilentBeep/releases).
2. Запустите установщик — он ставит приложение для текущего пользователя в `%LocalAppData%\SilentBeep\` и не требует UAC.
3. SilentBeep запустится сразу после установки и будет автоматически стартовать при входе в Windows (автозапуск включён по умолчанию; отключить можно в настройках).

Windows SmartScreen может предупредить о неизвестном издателе — нажмите **Подробнее → Выполнить в любом случае**. Подпись кода запланирована на будущую версию.

## Автообновления

SilentBeep раз в 6 часов проверяет GitHub Releases на новые версии (первая проверка через 30 секунд после запуска). Обновление скачивается в фоне и применяется при следующем запуске.

- Правый клик по иконке в трее → **Проверить обновления** — ручная проверка.
- Когда обновление скачано, в меню трея появляется **Перезапустить для обновления**; всплывающее сообщение тоже предлагает перезапуск.
- Автопроверку можно отключить в **Настройки → Обновления**. Ручная «Проверить сейчас» при этом продолжит работать.

## Использование

### Первый запуск

При первом запуске вы услышите приятный трёхнотный джингл, указывающий, что приложение работает. Иконка появится в системном трее (правый нижний угол экрана).

### Настройки

Правый клик по иконке в трее → **Настройки**:

**Основные**

- **Enabled** — включение/выключение keep-alive импульса.
- **Start with Windows** — автозапуск при старте Windows.
- **Play Startup Jingle** — проигрывать джингл при запуске.
- **Night Mode** — приостанавливать сигналы в ночные часы (например, 23:00–07:00).

**Аудио**

- **Interval (minutes)** — как часто играть импульс (1–120, по умолчанию 15).
- **Frequency (Hz)** — частота импульса (1–20000, по умолчанию 10).
- **Duration (ms)** — длительность импульса (1–1000, по умолчанию 5).
- **Output Device** — выбор аудиоустройства.
- **Restore Defaults** — сброс настроек аудио к значениям по умолчанию.

**Статус**

- **Last Beep At / Next Beep At** — время последнего и следующего запланированного импульса.
- **Last Beep Result** — результат последнего импульса и использованное устройство.
- **Effective Output Device** — фактически используемое устройство (может отличаться при fallback).
- **Fallback Active** — индикатор, что приложение переключилось на устройство по умолчанию.

### Меню трея

Правый клик по иконке в трее — быстрый доступ к:

- **Enabled** — включение/выключение keep-alive импульса.
- **Settings** — открыть окно настроек.
- **Check for updates** — ручная проверка GitHub Releases.
- **Restart to apply update** (только если скачанное обновление ждёт применения).
- **Exit** — закрыть приложение.

## Как это работает

SilentBeep проигрывает очень короткие низкочастотные аудиоимпульсы через заданные интервалы. Эти импульсы:

- **Неслышимы** — ниже порога слышимости человека (10 Гц сильно ниже границы 20 Гц).
- **Безопасны** — не навредят динамикам и аудиооборудованию.
- **Эффективны** — держат устройство в активном состоянии и готовым к мгновенному воспроизведению.

## Устранение неполадок

**Я не слышу ничего при запуске**

Стартовый джингл играет на выбранном устройстве. Если вы его не слышите — проверьте, что в настройках выбрано правильное устройство вывода.

**Импульс слышен**

- Уменьшите частоту до 5–10 Гц.
- Уменьшите длительность до 1–5 мс.
- Убедитесь, что выбрано правильное устройство вывода.

**Приложение не держит динамики активными**

- Проверьте, что **Enabled** включено в настройках.
- Убедитесь, что выбрано правильное аудиоустройство.
- Для проверки попробуйте уменьшить интервал до 1–5 минут.

**Настройки не сохраняются**

- Убедитесь, что есть права записи в `%APPDATA%\SilentBeep\`.
- Проверьте, что антивирус не блокирует приложение.

## Файл конфигурации

Настройки сохраняются в `%APPDATA%\SilentBeep\config.json`. Файл намеренно размещён в roaming-профиле (а не в папке установки), чтобы пережить удаление и переустановку. Можно редактировать вручную, но рекомендуется пользоваться окном настроек.

## Журналы

Файлы журнала пишутся в `%LocalAppData%\SilentBeep\logs\` с ежедневной ротацией (хранятся последние 7 дней). Приложите их к сообщению об ошибке.

## Приватность

SilentBeep **не собирает** телеметрию, аналитику или данные об использовании.

Единственные исходящие запросы — обращение к GitHub Releases API (`api.github.com`) раз в 6 часов для проверки новых версий. Передаётся только анонимный HTTP(S)-трафик без идентифицирующей информации.

Автопроверку можно полностью выключить в **Настройках → Обновления**. Даже при включённой проверке обновления скачиваются, но **никогда не применяются без вашего явного перезапуска**.

## Системные требования

- Windows 10 или новее.
- Любое устройство вывода звука.
