SilentBeep — это утилита для Windows, которая не даёт динамикам засыпать, периодически воспроизводя неслышимые аудиоимпульсы.

## Зачем?

Многие аудиоустройства переходят в спящий режим после периода бездействия, из-за чего появляется задержка, когда нужно воспроизвести звук. SilentBeep держит устройство в активном состоянии за счёт очень короткого низкочастотного импульса, который не слышен человеку.

## Возможности

- **Бесшумная работа** — частоты ниже порога слышимости (по умолчанию 10 Гц).
- **Работа в трее** — работает в фоне с иконкой в системном трее.
- **Автозапуск** — опциональный запуск вместе с Windows.
- **Настройка** — интервал, частота, длительность, i18n, темы.
- **Выбор устройства** — выбор аудиовыхода.
- **Ночной режим** — опциональная пауза сигналов в заданные ночные часы.

## Установка

1. Загрузите `SilentBeep-win-Setup.exe` со страницы [Releases](https://github.com/dosoft/SilentBeep/releases).
2. Запустите установщик — он ставит приложение для текущего пользователя в `%LocalAppData%\SilentBeep\` и не требует UAC.
3. SilentBeep запустится сразу после установки и будет автоматически стартовать при входе в Windows (автозапуск включён по умолчанию; отключить можно в настройках).

Windows SmartScreen может предупредить о неизвестном издателе — нажмите **Подробнее → Выполнить в любом случае**.

## Автообновления

SilentBeep раз в 6 часов проверяет GitHub Releases на новые версии (первая проверка через 30 секунд после запуска). Обновление скачивается в фоне и применяется при следующем запуске.

- Правый клик по иконке в трее → **Проверить обновления** — ручная проверка.
- Когда обновление скачано, в меню трея появляется **Перезапустить для обновления**; всплывающее сообщение тоже предлагает перезапуск.
- Автопроверку можно отключить в **Настройки → Обновления**. Ручная «Проверить сейчас» при этом продолжит работать.

## Использование

SilentBeep работает в системном трее:

- **Левый клик** — включить/выключить звуковые сигналы.
- **Двойной клик** — открыть окно настроек.
- **Правый клик** — открыть контекстное меню (настройки, обновления, выход).

Настройте поведение импульсов, выбор аудиоустройства, автозапуск, ночной режим и просмотрите статус работы в окне настроек.

## Устранение неполадок

**Я не слышу ничего при запуске**

Стартовый джингл играет на выбранном устройстве. Если вы его не слышите — проверьте, что в настройках выбрано правильное устройство вывода.

**Импульс слышен**

- Уменьшите частоту до 5–10 Гц.
- Уменьшите длительность до 1–5 мс.
- Убедитесь, что выбрано правильное устройство вывода.

**Приложение не держит динамики активными**

- Проверьте, что оно включено в настройках.
- Убедитесь, что выбрано правильное аудиоустройство.
- Для проверки попробуйте уменьшить интервал до 1–5 минут.

**Настройки не сохраняются**

- Убедитесь, что есть права записи в `%APPDATA%\SilentBeep\`.
- Проверьте, что антивирус не блокирует приложение.

## Файл конфигурации

Настройки сохраняются в `%APPDATA%\SilentBeep\config.json`. Файл намеренно размещён в roaming-профиле (а не в папке установки), чтобы пережить удаление и переустановку. Можно редактировать вручную, но рекомендуется пользоваться окном настроек.

## Журналы

Файлы журнала пишутся в `%LocalAppData%\SilentBeep\logs\` с ежедневной ротацией (хранятся последние 7 дней). Приложите их к сообщению об ошибке.

## Приватность

SilentBeep **не собирает** телеметрию, аналитику или данные об использовании.

Единственные исходящие запросы — обращение к GitHub Releases API (`api.github.com`) раз в 6 часов для проверки новых версий. Передаётся только анонимный HTTP(S)-трафик без идентифицирующей информации.

Автопроверку можно полностью выключить в **Настройках → Обновления**. Даже при включённой проверке обновления скачиваются, но **никогда не применяются без вашего явного перезапуска**.
